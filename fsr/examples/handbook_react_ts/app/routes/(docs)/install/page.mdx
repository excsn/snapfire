## Pages written in MDX

This page is `routes/install/page.mdx`. Its loader still runs first and the page reads what it returned as `props`, so the list above is {props.steps.length} steps from `src/content.ts`. An fsr reads MDX with its default features:

```sh title="terminal" {1}
cargo install snapfire_fsr_cli
fsr use app mdx
fsr build app
```

A build prints what it found, one row per kind:

```shell-session title="terminal"
$ fsr build app
routes    /install               routes/install
plan      generated/plan.sexp    18.7 KB written
```
